# 02: Goal-based warehouse agent
`warehouse_agent.py` parses the map, runs BFS and prints the path; `test_agent.py` checks path validity,
optimality against an independent shortest-distance computation, and the no-path case.

Run: `python warehouse_agent.py && python test_agent.py`

Result: 20 moves from S to G; path stays off every `#`. See `ANSWERS.md`, `report.pdf`.
